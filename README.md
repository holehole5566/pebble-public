# Pebble 🪨

情侶共享筆記 — 企鵝會把最美的鵝卵石送給喜歡的人。Pebble 讓你們分享生活中的美好。

## 功能

- ✏️ 共享筆記與待辦清單
- 🔖 一起收藏連結（Instagram、YouTube、網頁⋯）
- 🔒 端對端加密，只有你們看得到
- 🐧 專屬企鵝小島，記錄你們的每一天
- 🧩 Chrome 擴充功能，瀏覽網頁一鍵收藏
